🧩 Installer le bouton Overframe
Comment importer un build Overframe ?
  1. Installe l'extension Tampermonkey depuis le Chrome Web Store (une seule fois). Dans chrome://extensions, ouvre les Détails de Tampermonkey et active « Autoriser les scripts utilisateur » (sur les versions plus anciennes de Chrome : le mode développeur).
  2. Clique sur 🧩 Installer le bouton Overframe ci-dessus, puis sur Installer dans Tampermonkey.
  3. Cherche ta Warframe ou ton arme avec la barre ci-dessus, ouvre un build sur Overframe et clique sur ➕ Ajouter au tableau de bord en bas à droite : tu reviens ici avec le build.

Sans Tampermonkey (autre ordinateur…) : glisse ce favori dans ta barre de favoris et clique dessus depuis un build Overframe : 📥 Envoyer au tableau de bord
